TRY #001 · MOVE

RUNNING

You don't need to become a runner.
Let's just see if you like running.

HOW IT STARTED

I started running when I was a teenager.

I'd quit all the sports I was doing — mostly out of teenage rebellion — but I still wanted to do something. I just didn't really want to admit it, or have anyone know I was doing it.

So I went running.

I was already fit, so I ran about five kilometres from the start. I didn't have a running watch. I didn't have a training plan. I didn't know anything about pace, heart-rate zones or running technique.

This was before social media made recreational running something you saw everywhere. As far as I knew, people who ran were marathon runners.

I wasn't a marathon runner. I just went running.

And then I started testing my own limits. If I had more time, I'd see if I could go farther. If I had more energy, I'd see if I could go faster.

I didn't know how to be a runner.
I just tried running.

20 YEARS LATER

I've had breaks. I haven't been running continuously for twenty years. But somehow, running has always found its way back into my life.

Today I run because it makes me feel better. It's exercise, an outlet and time that's completely mine.

I never became a serious runner. I don't race. I still don't wear a running watch. I don't obsess over pace, distance or numbers.

I know much more about running now than I did when I started. I own several pairs of running shoes, a running vest and a few things I've picked up over the years because they turned out to be useful.

And yes — sometimes I buy running shoes simply because they're pretty.

Twenty years later, I'm still not trying to become a runner.
I just like running.

OK, I WANT TO TRY

BEFORE YOU BUY ANYTHING

Don't buy running gear yet. First, find out whether you actually like running.

YOU NEED

✓ Comfortable clothes you can move in

✓ Shoes suitable for running or a similar sports activity

✓ Your shoes firmly tied

✓ A little bit of time

YOU DON'T NEED YET

✕ A running watch

✕ A running vest

✕ Expensive running clothes

✕ Special running socks

✕ €200 running shoes

Already have a hoodie or vest with pockets? Great. Use that instead of buying a running vest. And yes, your socks with little flowers can absolutely be running socks.

Try first.
Buy later.

YOUR FIRST TRY

JUST GO RUNNING

01

WARM UP

Take a few minutes to warm up before you start. You're trying running — not trying to make tomorrow miserable.

02

START EASY

Don't worry about pace or distance. Run slowly. Walk if you need to. Run again if you feel like it.

03

STOP WHEN YOU'VE HAD ENOUGH

Your first run doesn't have to prove anything. Five minutes counts. Twenty minutes counts. Running and walking counts.

04

COOL DOWN

Walk for a few minutes and give yourself some time to cool down. Gentle stretching can feel good afterwards.
